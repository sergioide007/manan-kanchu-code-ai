What It Does

Six Layers of Code Intelligence

Each analyzer runs independently in parallel for speed. Together they give you a complete audit in seconds.

🔍

AI Code Detection

Hybrid scoring — 40% heuristic (comment density, naming patterns, structural uniformity) + 60% deep AI semantic analysis. Works on any programming language.

0–100% confidence score
🛡️

Vulnerability Scanner

20+ OWASP patterns: SQL injection, XSS, command injection, hardcoded secrets, AWS/GCP keys, path traversal, insecure redirects, weak randomness, and more.

OWASP Top 10 + CWE codes
☠️

Malicious Code Scanner

Detects credential theft, keyloggers, cookie exfiltration, form hijacking, crypto miners, clipboard hijack, and obfuscated payloads in web pages and scripts.

7 malicious pattern categories
📋

Policy Evaluator

10 built-in rules (no eval, no innerHTML, no hardcoded secrets, license compliance…) plus a DSL for custom organizational policies. Block PRs that violate them.

Custom rules supported
🖥️

Shell Analyzer

Inspects shell commands for destructive operations (rm -rf, mkfs), remote pipe execution, privilege escalation, and suggests safer alternatives inline.

15+ shell risk patterns
📊

Audit Dashboard

Dark-theme interactive dashboard with score breakdowns, file-level results, finding explorer, policy violations, and one-click report export (Markdown / JSON).

Export Markdown & JSON
How It Works

Detection in Three Steps

From a single file to an entire project, manan-kanchu gives you results in seconds.

1

Select Target

Run on the current file, a selection, or the whole project via command palette, right-click menu, or keyboard shortcut.

2

Parallel Analysis

All six analyzers run concurrently. Heuristics fire instantly; AI semantic analysis streams from your chosen provider.

3

Review & Act

Results appear in the dashboard with severity levels, affected lines, and actionable recommendations. Export or sanitize in one click.

Example Output

Human vs AI Code — Spotted Instantly

manan-kanchu highlights the linguistic and structural patterns that distinguish AI-generated code from human-authored logic.

Human-authored — auth.ts 
// hard-won lesson: JWT exp must match
// session cookie max-age or we get
// phantom logouts on mobile Safari
function createSession(user) {
  const exp = Date.now() + SESSION_TTL;
  const token = jwt.sign(
    { sub: user.id, exp },
    process.env.JWT_SECRET
  );
  return { token, exp };
}
✓ Score: 12% — Likely human-written
AI-generated — helpers.ts 
/**
 * Validates user input and returns
 * a boolean indicating validity.
 */
function validateUserInput(input) {
  if (!input || input.length === 0) {
    return false;
  }
  return true;
}
