# Privacy Policy — manan-kanchu AI Code Detector

**Effective date:** 2026-05-26  
**Extension version:** 1.0.0  
**Publisher:** sergioide007  

---

## 1. Overview

manan-kanchu is an open-source VS Code extension. This policy explains what data the extension accesses, what it sends externally, and what it never does.

**Short version:** manan-kanchu is privacy-first. Your code stays on your machine by default. We do not collect, store, or sell any personal data.

---

## 2. Data the Extension Accesses Locally

| Data | Purpose | Leaves your machine? |
|------|---------|----------------------|
| Source code in open files | Analysis by the selected AI provider | Only if a cloud provider is configured |
| File paths within your project | Display in dashboard and reports | No |
| VS Code workspace configuration | Read `manan-kanchu.*` settings | No |
| API keys for cloud providers | Authenticate AI requests | Transmitted only to the respective provider API |

---

## 3. AI Providers and Data Transmission

manan-kanchu supports five AI providers. **Only the provider you configure receives data.**

### 3.1 Local Providers (code never leaves your machine)

- **Ollama** — runs models locally at `http://localhost:11434`. No network traffic.
- **LM Studio** — runs models locally at `http://localhost:1234`. No network traffic.

### 3.2 Cloud Providers (code sent to third-party APIs)

If you configure a cloud provider, code snippets (truncated to 3 000 characters maximum) are sent to the provider's API for analysis.

| Provider | Privacy policy |
|----------|---------------|
| Anthropic (Claude) | https://www.anthropic.com/privacy |
| Google (Gemini) | https://policies.google.com/privacy |
| OpenAI (GPT) | https://openai.com/policies/privacy-policy |

**Default behaviour:** manan-kanchu selects local providers first (Ollama → LM Studio). Cloud providers are only used if no local provider is available **and** you have entered an API key via the *Configure AI Provider* command.

---

## 4. API Key Storage

API keys are stored exclusively in **VS Code SecretStorage**, which delegates to the operating system's keychain (macOS Keychain, Windows Credential Manager, Linux libsecret). Keys are:

- Never written to disk files
- Never included in settings JSON (`settings.json`, `.vscode/`)
- Never transmitted anywhere except directly to the respective provider API over HTTPS
- Deletable at any time via the *Configure AI Provider* command (leave the key field blank to remove)

---

## 5. Audit Reports

Reports generated by *Generate Audit Report* are written to `.manan-kanchu/report-<timestamp>.md` inside your project directory. They contain file paths, finding descriptions, and code snippets. They are local files — manan-kanchu does not upload them anywhere.

---

## 6. Telemetry

manan-kanchu includes an optional telemetry setting (`manan-kanchu.privacy.telemetry`). It is **disabled by default** and the extension sends no usage data in its default configuration.

If enabled in a future release, telemetry would be anonymous aggregate counts (e.g., number of scans) with no code content, file names, or personal identifiers.

---

## 7. No Tracking, No Analytics, No Ads

manan-kanchu does not:

- Track your coding activity
- Record keystrokes or clipboard contents
- Display advertisements
- Sell data to third parties
- Require account registration
- Communicate with any server operated by the extension authors

---

## 8. GDPR Compliance (EU/EEA Users)

Under the General Data Protection Regulation (GDPR):

- **Legal basis:** The extension processes code locally as a tool you install voluntarily (legitimate interest / contract performance). Cloud API calls are initiated by you explicitly.
- **Data minimisation:** Only the code snippet needed for analysis (max 3 000 chars) is sent to cloud providers when configured.
- **Right to erasure:** Delete your API keys via the extension or your OS keychain. Delete generated reports from your `.manan-kanchu/` folder. Uninstalling the extension removes all stored keys.
- **Data controller:** When using cloud providers, you are the data controller for your code; the respective provider is a data processor.

---

## 9. CCPA Compliance (California Users)

manan-kanchu does not sell personal information. It does not collect personal information as defined under the California Consumer Privacy Act. No opt-out mechanism is required because no data is collected or sold.

## 10. Children's Privacy
